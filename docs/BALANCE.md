# Balance & Logic Notes (GDD 고도화 결정 사항)

기획서(`docs/GDD.md`)의 공식은 그대로 유지하고, 기획서가 비워둔 수치/규칙을 아래처럼 확정했습니다.
모든 상수는 `src/config/balance.js` 한 곳에 있고, `tests/`에서 검증됩니다.

## 2. 기획서에 없어서 정한 것

### 영웅 성장
- **ATK** = `floor(base × 1.10^(Level-1) × StarMult)`, **HP** = `floor(base × 1.08^(Level-1) × StarMult × (1+의자 보너스))`
- 레벨당 ATK 성장(1.10) < 비용 성장(1.12) 이라서 레벨만으로는 서서히 벽에 부딪히고, 벽은 **승급(별) / 새 영웅 / 오프라인 보상**으로 뚫는 구조입니다.
  - 스테이지 1개 오를 때 필요한 DPS 1.18배 ≈ 1.8레벨, 비용은 1.12^1.8 ≈ 1.23배 증가 vs 골드 수입 1.15배 증가.
- **StarMult** ★1~★5 = `1 / 1.25 / 1.6 / 2.1 / 2.8`
- 등급별 기본 스탯(ATK/HP): Standard 6/100, Advanced 8/130, Executive 11/160, CEO 15/200
- 역할 보정: Tank ATK×0.6 HP×2.0 / Melee ×1.0 ×1.0 / Ranged ×1.1 ×0.7 / Healer ×0.5 ×0.8
- 공격 간격: Melee 1.0s, Tank 1.2s, Ranged 1.2s, Healer 1.5s. 사거리: 근접 0.6셀, 원거리 5셀.

### 몬스터 / 보스
- 몬스터 ATK = `floor(1 × 1.13^(Stage-1))`, 공격 간격 1.5s. (초기값 3/1.15 였으나 시뮬레이션 결과 시작 영웅 1명이 첫 스테이지도 못 깨서 하향)
- 보스: HP = 몬스터HP × **8**, ATK ×3, 골드 ×20, 30초 제한. 실패 시 이전 스테이지로 후퇴하여 루프.
- 파티 전멸 시 1스테이지 후퇴(단, Phase 1-1에서는 진행도 유지).
- 영웅 사망 → 8초 후 완전 회복 부활. 생존 중 초당 최대 HP 2% 자연 회복.

### 타겟팅 / 배치
- 슬롯: front(1) / mid(2) / back(2). 탱커→front, 근접→mid, 원거리·힐러→back 우선, 비어 있으면 다음 슬롯으로.
- 몬스터는 85% 확률로 탱커를 노리고, 나머지는 가장 앞선 영웅을 노림.
- 힐러는 아군 HP 60% 미만이 있으면 공격 대신 힐(ATK×2.5).

### 스킬 (승급 의미 부여)
- ★2에 해금, ★4에 위력 ×1.5, ★5는 캔버스에 금색 글로우.
- strike(단일 ×3~5) / sweep(전체 ×1.2~2) / buff(파티 ATK +20~35%, 5초) / heal(전체 25~30%) / ult(전체 ×3~4 + 2초 스턴)

### 가차 / 보석 경제
- 뽑기: 1회 100젬, 10회 900젬. 시작 보석 **1,000** (첫 세션에 10연차 1회 가능).
- 확률 60/30/9/1. 천장: 50회 내 Executive+ 보장(소프트), 100회 내 CEO 보장(하드). 카운터는 획득 시 리셋.
- 신규 캐릭터는 즉시 ★1 해금(GDD의 "조각 10개 해금"을 뽑기 1회 = 조각 10개로 해석), 중복은 조각 5~10개.
- 승급 조각: GDD 표 그대로(Standard 10/20/40/80 … CEO 25/50/100/200).
- 보석 수입: 스테이지 첫 클리어 10, 재클리어 1 / 보스 첫 클리어 50, 재클리어 10. → 스테이지당 약 1회 뽑기 페이스, 100스테이지 ≈ CEO 천장 1회.

### 오프라인 / 백그라운드
- `goldPerSec(stage) = baseGold × goldMult × min(5, 1 / (HP/DPS + 1s 리스폰 + 1s 이동))`
- 앱을 다시 열 때 60초 이상 지났으면 정산 + Excel 다이얼로그. 탭이 30초 이상 멈춰 있었던 경우(rAF 정지)에도 같은 공식으로 자동 정산.
- 저장: 10초마다 + 탭 숨김/종료 시 localStorage. Export/Import 문자열 지원.
